1. Downloads-এ **`Aminur-Fiverr-Gig-2`** নামে নতুন ফোল্ডার বানাও (Gig 1-এর ফোল্ডার থেকে আলাদা)।
2. `media/`-এর ৪টা ফাইল ওই ফোল্ডারে রাখো।
3. Fiverr-এ aminur_rex দিয়ে লগইন করে Claude extension-এ `claude-chrome-prompt.md`-এর বক্সের লেখা paste করো।
